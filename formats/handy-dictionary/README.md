# Handy-Dictionary format

This directory holds an import-ready artifact for the third-party Handy-Dictionary fork:
<https://github.com/pupontech/Handy-Dictionary>

The fork adds bulk import/export to Handy's Word Replacements feature. The generated
`dictionary.json` here uses the verified fork schema and can be imported directly.

## `dictionary.json`

```json
{
  "schema": "handy-dictionary",
  "version": 1,
  "customWords": [],
  "replacements": [
    {"from": "<mistranslation>", "to": "<correction>"}
  ]
}
```

- `from` is the wrong form Parakeet emits.
- `to` is the intended correction.
- `customWords` is intentionally empty here; `formats/vocabulary/all.txt` is the companion plain-text vocabulary list.

This file is generated by `scripts/build_outputs.py` and validated against the schema.

## Pending CSV

A CSV export matching the fork's `from,to` header is intentionally **cut** until the
fork's parser documents its expected import headers unambiguously. Once that is
confirmed, `scripts/build_outputs.py` will emit `replacements.csv` here. The
`.gitignore` line for `replacements.csv` remains in place.

## Companion files

- `data/all.json` — the same replacement pairs in the upstream `word_replacements` array shape.
- `formats/vocabulary/all.txt` — the intended correction words as a plain vocabulary list (useful as Whisper custom-word bias, inert for Parakeet).
